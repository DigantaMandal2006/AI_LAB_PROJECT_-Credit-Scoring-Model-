About Dataset
Problem Statement

The dataset contains personal, banking, and credit-related information collected from customers of a global finance company. The objective is to develop an intelligent machine learning system that can classify customers into different credit score categories, helping reduce the manual effort involved in credit assessment.

Task

The goal of this project is to build a machine learning classification model that predicts a person's credit score based on their financial, banking, and credit-related information.

The target variable, Credit_Score, consists of three categories:

Good

Standard

Poor

Dataset Information

The dataset contains two files:

train.csv — Used for training and evaluating machine learning models.

test.csv — Contains unseen customer records for making predictions.

The dataset contains 55 columns and includes information related to customer demographics, income, occupation, banking details, loans, credit history, payment behavior, and other financial attributes.

Important Features

Some of the important columns include:

Feature	Description
ID	Unique identification of an entry
Customer_ID	Unique identification of a customer
Month	Month associated with the customer's record
Name	Name of the customer
Age	Age of the customer
SSN	Social Security Number
Occupation	Customer's occupation
Annual_Income	Annual income of the customer
Monthly_Inhand_Salary	Monthly base salary
Num_Bank_Accounts	Number of bank accounts held by the customer

The dataset also contains several credit and financial features such as the number of credit cards, loans, outstanding debt, credit history, delayed payments, payment behavior, and monthly balance.

Data Quality

The dataset contains several real-world data-quality issues, including:

Missing values

Invalid or inconsistent entries

Incorrect data types

Outliers

Duplicate or repeated customer records

Special characters and corrupted values

Inconsistent categorical values

Therefore, data cleaning and preprocessing are important steps before applying machine learning algorithms.

Dataset Type

Objective

The primary objective of this project is to analyze customer financial data, perform the necessary preprocessing and feature engineering, and develop a machine learning model capable of accurately classifying customers based on their credit score.

Dataset Source

The dataset is available on Kaggle under the Credit Score Classification dataset: https://www.kaggle.com/datasets/parisrohan/credit-score-classification.
