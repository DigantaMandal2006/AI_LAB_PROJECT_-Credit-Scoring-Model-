Credit Score Classification
📌 Overview

This project focuses on building a Machine Learning classification model to predict a customer's credit score based on their financial, banking, and credit-related information.

The model classifies customers into three credit score categories:

Good

Standard

Poor

🎯 Objective

The main objective is to develop an intelligent system that can automatically classify customers based on their credit-related information, reducing the need for manual credit assessment.

📊 Dataset

The dataset contains customer information such as:

Age and Occupation

Annual Income and Monthly Salary

Number of Bank Accounts

Credit Cards and Loans

Outstanding Debt

Payment Behaviour

Credit History

Delayed Payments

The dataset contains 55 columns and is provided in train.csv and test.csv files.

🛠️ Project Workflow

Data Collection → Data Cleaning → EDA → Feature Engineering → Model Training → Model Evaluation → Prediction

🤖 Machine Learning

This is a multi-class classification problem. Different machine learning algorithms can be trained and evaluated to predict the Credit_Score target variable.
